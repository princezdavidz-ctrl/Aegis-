# AEGIS Specialist Agent Catalogue

| Agent | Responsibility |
|---|---|
| Asset Intelligence | Authorized asset inventory and context |
| Threat Detection | Telemetry analysis and suspicious activity |
| Vulnerability Intelligence | Weakness prioritization |
| Threat Intelligence | External indicator and behavior enrichment |
| Incident Investigator | Evidence correlation and timelines |
| Malware Analysis | Safe artifact analysis |
| Response Planner | Defensive response proposals |
| Patch Engineer | Proposed fixes and isolated testing |
| Compliance Intelligence | Framework mapping and evidence |
| Reporting Intelligence | Customer and SOC reporting |

Each agent must declare its input/output schema, capabilities, data classification, permitted tools, tenant requirements, failure behavior and evaluation tests.
