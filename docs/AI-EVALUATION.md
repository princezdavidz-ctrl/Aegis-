# AEGIS AI Evaluation and Improvement

Evaluate each agent and model/prompt release against versioned datasets and adversarial scenarios. Measure factual correctness, evidence citation quality, detection precision/recall where applicable, false-positive burden, tenant isolation, policy compliance, tool-use safety, latency and cost.

Engineer-reviewed outcomes may be curated into offline evaluation datasets. Changes require regression checks and release approval. Live customer telemetry must not silently become training data.
